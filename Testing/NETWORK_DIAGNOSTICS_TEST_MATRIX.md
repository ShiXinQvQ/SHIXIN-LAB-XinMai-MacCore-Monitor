# 「芯脉」网络诊断测试矩阵

适用版本：0.3.0-beta（build 300）
建立日期：2026-07-28

## 自动可复现测试

由 `ShixinStressPowerSelfTest` 执行：

| 场景 | 通过标准 |
|---|---|
| ipwho.is 解析 | IPv4、国家、ASN、组织、时区正确解析 |
| proxycheck.io v3 解析 | VPN、Proxy、Hosting、风险值、供应商置信度、最后发现、攻击分项求和与 ASN 正确；`warning` 有效主体可降级使用 |
| 五目标全成功 | 国际评分 100，完整度和置信度为 100% |
| 单目标 DNS 失败 | 仅该目标不可用；整体降级但不把全部国际网络判死 |
| 离线/超时/连接失败/重置/TLS 失败 | 均不得显示成功或极佳 |
| HTTP 429/服务限流 | 标记“目标服务响应异常/部分异常”，不直接判 VPN 失效 |
| 用户取消 | 分数为空、状态为数据不足，不保存伪完成记录 |
| IP 信誉 | VPN、Hosting 与恶意/滥用风险分开表达 |
| 隐私一致性 | IPv4/IPv6 地区和 ASN 分流会扣分；DNS/WebRTC 显示未验证 |
| 综合评分数据不足 | 只有一个评分来源时不生成综合百分比 |
| 历史保存 | 独立 JSON、原子写入、数量上限、倒序、完整 IP 不落盘 |

执行：

```bash
swift run ShixinStressPowerSelfTest
```

## 本机运行检查

| 场景 | 操作 | 通过标准 |
|---|---|---|
| 标准测速回归 | 主动开始一次标准测速 | 下载、上传、延迟、抖动、RPM、流量、历史均正常 |
| 国际诊断正常网络 | 不勾选 IP 分析并主动开始 | 五目标各做 3 次，小流量、可取消、阶段耗时和最终域名可查看 |
| IP/信誉查询 | 阅读提示后点击“同意并查询” | 第三方提示在先；失败时本机详情仍可看；不显示虚假满分 |
| IPv4-only | 在无公网 IPv6 的网络运行 | IPv4 结果可用，IPv6 显示不可用，不把单栈本身判为恶意 |
| IPv6-only | 在无公网 IPv4 的网络运行 | IPv6 结果可用，IPv4 显示不可用；Provider 不支持时明确降级 |
| 双栈 | IPv4/IPv6 均可用 | 分别展示两个出口；地区/ASN 差异才提示潜在分流 |
| 断网 | 关闭网络后主动开始 | 及时失败/离线，不死锁、不写伪成功历史 |
| DNS 失败 | 使用受控无效 DNS 环境 | 5 秒内返回 DNS 失败或超时，可立即取消 |
| 单目标失败 | 受控拦截一个目标 | 其余目标继续完成，整体为“部分完成” |
| Provider 不可用 | 受控拦截 ipify/ipwho/proxycheck | Sheet 不会卡死；本机详情、已有国际结果仍显示 |
| 网络切换 | 诊断中切换 Wi‑Fi/有线/VPN | 不崩溃；本轮按实际阶段降级，下一轮读取新路径 |
| 敏感信息 | 首次打开网络详情 | IP、MAC、BSSID、SSID/位置默认遮罩，主动切换后才显示 |
| 取消后重启 | 测试中取消并等待按钮恢复 | 旧任务完全退出后才允许新任务，不串台 |

## 发布门禁

- `plutil -lint`：中、英、日三套本地化均通过。
- Debug 与 Release 全产品编译通过。
- `ShixinStressPowerSelfTest` 通过。
- 新 `.app` 结构、版本、Helper 与签名验证通过。
- 新 App 实际启动，不崩溃，标准/国际模式切换与网络详情 Sheet 正常。
- 源码与 App 包扫描无 API Key、token 或新增 Helper 网络访问。

真实断网、IPv6-only、网络切换和多机视觉检查必须在对应环境执行；未执行不得写成通过。
